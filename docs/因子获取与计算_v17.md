# 标普500正式模型 v17：数据获取、计算和每日运行

模型版本：`hybrid-pe-split-financial-exit-v17-20261016`。本文件对应 `monitor_v17/model.json` 中的正式表达式。年份是研究来源标签，没有年份过滤。三个入场、两个可执行离场；统一离场内含三个情景。监控程序发送信号报告，不连接券商，不声称知道用户实际持仓。

## 1. 正式组合

|组合|完整条件，`AND` 为同时满足，`OR` 为至少满足一个|
|---|---|
|独立金融离场（2007）|NFCI_4w_down AND FSX≤−10% AND FCS≥1.00个百分点|
|统一离场|NFCI_26w_up AND DEFENSE AND P+ AND [(Y− AND NSX≥40%) OR CPI同比<0% OR CPI同比≥5.39%]|
|深跌修复入场|S−6 AND S−≥P99 AND VIX≥V_c+3σ AND (NFR≥0.958 OR ERX达标)|
|高通胀回撤入场（2022）|P95≤S−<P99 AND CPI同比≥5.39% AND E−2 AND NFCI<0|
|白银坑入场|P95≤S−<P99 AND HPG>0 AND VIX≥V_c+3σ AND Sσ_200≤−2σ AND NOT(CPI同比≥5.39%)|

独立金融离场没有 NFCI>0、26周上升、DEFENSE、估值、S 或 F− 的附加要求。2020 专用组合已退出执行。统一离场的三个情景只作诊断，不能算作额外交易。离场优先，未知维持原状态。研究执行口径为信号后下一美股交易日收盘、全仓／空仓、单边成本5基点；本程序只报告信号。

## 2. 每天的数据截面和原始来源

GitHub Actions 每天 UTC 22:30（北京时间次日06:30）启动。以 XNYS 日历确认已收盘至少60分钟的最近交易日；夏令时通常在收盘后150分钟、冬令时90分钟启动。工作流实际启动可能有排队延迟。周末和休市日仍发送日报，并明确显示最近交易日，不制造新价格行。

|原始输入|自动获取地址／标识|观察值、单位和时效|
|---|---|---|
|标普500价格指数|Yahoo chart API `^GSPC`，`https://query1.finance.yahoo.com/v8/finance/chart/%5EGSPC`|非复权指数收盘，保留公布的两位小数；1957-01-02至2026-02-27使用已验收研究种子，仅追加之后的实际交易日。|
|纳斯达克100|同一 chart API，`^NDX`|非复权指数收盘，两位小数；同日与SPX配对。|
|VIX|同一 chart API，`^VIX`|VIX日收盘，不使用盘中最新值；下载2015年以来历史供平静期计算。|
|金融／基准ETF|同一 chart API，`XLF`、`SPY`|使用 `indicators.adjclose` 复权收盘，包含拆股和分红调整；不使用普通close代替。|
|周期／防御ETF|同一 chart API，`XLY XLI XLB XLP XLV XLU`|六只ETF的同口径复权收盘，按同一XNYS交易日历计算；缺价不填充、不删除日期。|
|NFCI|[FRED NFCI](https://fred.stlouisfed.org/series/NFCI)，原发布方芝加哥联储|原生周五观察值。通常次周三08:30美东发布；周一至周三有联邦假日则周四。线上以FRED初次发布记录核验可用日期。所有NFCI因子共用同次抓取的版本。|
|国债收益率|[DGS10](https://fred.stlouisfed.org/series/DGS10)、[DGS2](https://fred.stlouisfed.org/series/DGS2)|每日百分数报价，最新同日有效配对，最多允许5个日历日的正常假日间隔。|
|金融融资报价|[DCPF3M](https://fred.stlouisfed.org/series/DCPF3M)、[DTB3](https://fred.stlouisfed.org/series/DTB3)|3个月AA金融商业票据与3个月国库券利率，单位均为百分数；先配对每日报价再求周均。|
|总体CPI|[CPIAUCSL](https://fred.stlouisfed.org/series/CPIAUCSL)|总体季调CPI月指数；不是核心CPI。使用最新已发布观察月及同次抓取的去年同月值。|
|经济活动扩散指数|[CFNAIDIFF](https://fred.stlouisfed.org/series/CFNAIDIFF)|芝加哥联储CFNAI扩散指数，月度，两位小数。沿用正式规则：实际发布日之后的首个美股交易日起可用。|
|住宅建筑许可|[PERMIT](https://fred.stlouisfed.org/series/PERMIT)|月度住宅许可、季调年率、千套；实际发布日之后的首个美股交易日起可用。|
|预期PE和EPS|[FactSet Earnings Insight](https://insight.factset.com/topic/earnings) 官方周报PDF；固定官网路径 `advantage.factset.com/hubfs/Website/Resources%20Section/Research%20Desk/Earnings%20Insight/EarningsInsight_MMDDYY.pdf`，同时检查A/B版本|仅提取当期S&P500未来12个月预期PE。核验PDF首页发布日期、当期估值语句、正数范围；保存来源、发布日期、观察日、SHA256。EPS按同观察日SPX÷该PE。不能使用滚动实际PE、SPY PE或常数21。|

FRED API 使用 `fred/series/observations`：`realtime_start=realtime_end=截面日`，获取该日可得修订版本；使用 `output_type=4` 的初始发布记录核验近期周／月观察值的首次发布日期。月度数据在日频报告中保持至下一次可用发布。抓取失败会明确影响相关因子；不将失败当作0。

线上每日保存当时取到的输入和结果，之后不回写旧日报。宏观历史值可能被源站修订，所以重新下载当前版本复算旧日期，与当时保存的日报不一定相同。历史研究中的CPI、ERX、HPG模拟发布日期，仅用于历史复盘；线上使用核实的可用日期。不能把历史复盘称为完整的历史实时版本回测。

## 3. 20个正式因子的计算

所有日窗口按同一XNYS交易日历，不以CSV行数或日历天数代替。原始历史价格中不在正式交易日历上的记录不会进入窗口。数值使用全精度计算；报告显示的四舍五入值不参与判断。

|因子|精确定义与边界|含义|
|---|---|---|
|S−6|`S_t < S_(t−126)`，且最近126个交易日中 `S_i < S_(i−1)` 的天数≥61；两个条件AND。|中期下跌，非连续六个月或126日全跌。|
|S−≥P99|`D_t=1−S_t/max(S_≤t)`；`D_t≥P99_t`。P99见下一节，等号满足。|已达到历史完整回撤轮次的深跌边界，不是股灾必然性的预测。|
|P95≤S−<P99|`P95_t≤D_t<P99_t`。|值得关注的中等回撤区间，上界不含等号。|
|V≥V_c+3σ|最近252个交易日内，选择 `D_i<10%` 且VIX有效的平静日。若不足63个，向前取最近63个平静日；总历史不足63个则未知。`V_c`为这些样本均值，σ为样本标准差（ddof=1）；当日VIX≥均值＋3σ。|相对于平静期的极端恐慌；平静期固定10%是原正式VIX基准定义，不是组合里的价格入场分档。|
|Sσ_200≤−2σ|`dev_t=S_t−MA200_t`；`z_t=dev_t / sample_std(dev_(t−251:t))`；`z_t≤−2`。均线、标准差窗口均含当日。|价格相对自身200日均线明显超跌。|
|NFCI_4w_down|最新可用原生周值 `<` 同序列4个日历周前。周序列补齐W-FRI空位，不能跳过缺周；按千分点整数比较，严格小于。|金融条件相对四周前回落，不要求NFCI为正或逐周连续下降。|
|NFCI_26w_up|最新可用原生周值 `>` 26个日历周前；同样保持缺周并按千分点整数比较。|金融条件相对半年前收紧，可以仍为负。|
|N<0|最新可用NFCI严格小于0。|金融条件比长期平均宽松，不代表正在改善。|
|NFR≥0.958|当周及此前51个连续周NFCI的最大值−当周NFCI；≥0.958点。必须有完整52周，按千分点整数计算。|相对过去一年最紧时的修复幅度，原研究Ⅱ档。|
|ERX达标|`L=min(CFNAIDIFF最近36个连续月，含本月)`；`ERX=当月−L`；`L≤−0.27 AND ERX≥0.50`。缺月为未知，按百分点整数精度处理原指数的两位小数。|整体经济活动由明显低谷回升。|
|HPG>0|`M_t=mean(PERMIT_t,PERMIT_(t−1),PERMIT_(t−2))`；`HPG=M_t/M_(t−12)−1`；严格>0。|住宅建设意向的平滑同比仍增长。|
|CPI_y≥5.39%|`CPI_y=100×(CPIAUCSL_m/CPIAUCSL_(m−12)−1)`；≥5.39%。|固定高通胀档位，不自动重估。|
|CPI_y<0%|同一总体季调同比严格<0。|总体物价低于去年同期。|
|Y−|最新同日可得的 `DGS10−DGS2<0`，单位为个百分点。|收益率曲线倒挂。|
|NSX≥40%|`NSX=(NDX_t/SPX_t)/(NDX_(t−252)/SPX_(t−252))−1`；≥0.40。|纳指100相对标普的比值涨幅，不是两指数收益率相减40个百分点。|
|FSX≤−10%|`FSX=(XLF_adj_t/SPY_adj_t)/(XLF_adj_(t−252)/SPY_adj_(t−252))−1`；≤−0.10。|金融板块相对大盘走弱，不是金融股绝对跌幅。|
|FCS≥1.00pp|每日 `DCPF3M−DTB3`，仅同日报价均有效才配对；按周五结束的一周求均值，有几天用几天，至少1天。周完成后、报价按T+1联邦工作日可得时生效；周均≥1.00个百分点（100基点）。整周无配对报价则沿用最近有效周，超过14天只提示沿用，不清空；同时显示来源周、可用日、有效天数。|金融机构短期融资风险溢价升高。|
|DEFENSE|周期组XLY/XLI/XLB、防御组XLP/XLV/XLU，各组归一化复权价取几何平均；两组比值相对126交易日前的变化率<0。比较前按百分数保留10位小数以消除浮点噪声。|周期板块相对防御板块变弱。|
|P+|最新可用未来12个月预期PE `>` 最近260个原生周PE均值＋1个样本标准差（ddof=1）；窗口含本周且必须完整。|相对自身近五年估值偏高，不是绝对PE固定门槛。|
|E−2|最新可用预测EPS `<` 4个原生周前EPS `<` 8个原生周前EPS；严格不等式，三端点缺任一个即未知。|盈利预期连续两段下修，不要求每周下修。|

EPS/PE每个发布周选择最近一期FactSet周报，下一周首个美股交易日起生效。使用周报估值日价格；遇非交易日，沿用已批准的前4日内最近实际收盘查找规则，保存实际价格日期。新周无报告时，沿用最近FactSet的**原观察日价格和PE**，不以新股价重新计算旧EPS。260周窗口中历史美联储补缺和新周沿用的数量在报告中注明。2026-02-27之后不再引入事后美联储月度估值补缺。已批准的历史混合周序列作为不可变预热种子保留。

## 4. 每天的P95和P99

1. 读取1957年起真实交易日收盘，维护历史最高收盘价。达到或超过此前历史最高收盘时，上一轮回撤结束；连续创新高不制造零跌幅轮次。
2. 每轮只取一个最大回撤 `d=1−谷底收盘/前高收盘`，峰值日须≥1975-01-01。
3. 对交易日`t`，先从**截至上一实际交易日**已经恢复前高的完整轮次构建样本，然后才读取`t`收盘计算当日回撤。当天刚完成的轮次只能从下一交易日起进入分位数。
4. 未恢复前高的当前回撤排除；每轮权重相同，至少100轮。不使用未来价格，不使用时间衰减，不用每天的回撤值作为独立样本。
5. 将`n`个回撤升序排为`x[0]…x[n−1]`。对`p=0.95/0.99`，令`h=(n−1)p`、`j=floor(h)`、`g=h−j`，`Q(p)=x[j]+g×(x[min(j+1,n−1)]−x[j])`。这是Type 7线性分位。
6. P95是历史完整轮次中接近最深5%的关注边界；P99是接近最深1%的深跌边界。它们不是未来下跌发生概率，也不是恒定的8.08%或25.88%。报告展示样本轮数、输入截止日、两个最新边界。

## 5. 失败、缺数、邮件和可追溯性

- HTTP请求有超时、重试和来源校验；HTTP成功但JSON无法解析、结构不完整或最新收盘无效也会重试。请求失败保留缓存来源元信息。FCS和CFNAI按下述沿用政策处理，其他来源失败仍标记相关因子未知；缓存不冒充新数据。
- Yahoo最新日线行有时延迟，`close`和`adjclose`均为空，而`regularMarketPrice`已是收盘值。只在目标日期等于最新报价日期、`regularMarketTime`位于XNYS实际收盘时刻至其后5分钟内、运行已超过收盘60分钟时，才用该常规时段收盘报价补齐最后一行。最新报价日复权因子为1，前序历史仍使用原返回的复权值；不使用盘后、盘中或异日报价。补齐证据及时间保存在来源元信息中。
- 标普价格在1975年后的实际交易日缺失，无法可靠重建轮次，整次有效信号计算中止并发异常报告；不填充价格。
- NFCI应发布新周而未取得时标为未知。CFNAI取消“观察月第一天超过80天”的限制，每次读取芝加哥联储官方发布日历，并保留缓存。下一期发布前沿用最近已发布数据，按原规则从发布后的首个交易日起采用新值；到期未取得先提示并沿用，超过计划发布日期7个日历日仍未取得才标记持续延迟或采集异常。日历未覆盖下一期需明确报错，不能无限静默沿用。PERMIT/CPI原有时效校验保持。
- FCS按实际配对天数计算；没有新有效周时持续保留旧周值并披露日期，不以零替代，完全没有任何历史配对值时仍明确报告无法计算。FactSet保持原沿用规则。
- 三态逻辑：`False AND Unknown=False`，`True AND Unknown=Unknown`；`True OR Unknown=True`，`False OR Unknown=Unknown`；`NOT Unknown=Unknown`。缺一个因子不代表所有组合都未知；报告逐组合判断。
- 邮件通过Gmail SMTP_SSL 465，发件／默认收件邮箱取现有 `EMAIL_ADDRESS` Secret，密码取 `EMAIL_PASSWORD` Secret；可用仓库变量 `EMAIL_RECEIVER` 明确设置其他收件地址。FRED密钥仅取 `FRED_API_KEY` Secret。
- 正文和HTML附件包括组合公式、状态、全部20因子输入、源观察日、发布日期、异常、模型版本及代码提交。SMTP返回失败会让工作流失败，不打印“发送成功”。同UTC日、行情截面、模型版本、健康状态成功发送后记录回执，正常重跑不重复发送；同日收盘后出现新行情截面仍发送新报告，异常恢复后也可另发一次恢复日报。
- `data`分支保留v17输入CSV、日快照、周PE记录、完整回撤轮次和邮件回执，不覆盖旧版历史数据。工作流以普通提交推送，不force push。原始响应的校验值记录在数据元信息中，临时原始文件仅放运行制品；FactSet整份PDF不向data分支或制品再分发。
- 原始输入有缺失和接口变动的可能，不能保证未来永不缺数。程序将其明确报告，不能默认为无信号。GitHub调度与SMTP故障需从Actions运行状态追踪。

## 6. 验证和版本

`tests/fixtures/parity_summary.json` 记录：1995-01-03至2026-02-27的7,841日五组合结果一致；SPX、MA200、偏离σ、126日计数、VIX基准、P95/P99、FSX、NSX、板块相对变化等原始重算中间量一致；15个关键日期全部20因子一致，覆盖2007金融离场和2020融资报价缺失等情形。

回归测试覆盖三态金融离场27种输入、NFCI负值／相等／缺周、P99因果顺序、FactSet沿用保持原价、完整历史组合日期。新增覆盖FCS单日／双日／空周沿用、CFNAI发布日历边界、Yahoo延迟日线及盘中／盘后拒绝、无效JSON重试和缓存发布日期保留。

2026-10-25按用户要求启用线上采集政策`live-data-20261025`。冻结研究模型、历史因子和回测基线保持可追溯，研究内核中的旧FCS三日／14天测试只验证旧版历史合同；线上使用`monitor_v17/data_policy.py`的新规则。新采集政策的FCS历史效果未冒充已经重新回测的结果。手动工作流默认只验证不发邮件，定时工作流继续发日报。
